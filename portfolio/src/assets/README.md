# Portfolio Assets

This directory contains static assets for the portfolio website.

## Required Images

Please add the following image files to this `assets/` directory:

### Profile Image
- `profileImage.png` - Your profile picture (recommended: 400x400px, PNG format)

### Social Media Logos
- `linkedInLogo.png` - LinkedIn logo/icon (recommended: 50x50px, PNG format)
- `githubLogo.png` - GitHub logo/icon (recommended: 50x50px, PNG format)
- `facebookLogo.png` - Facebook logo/icon (recommended: 50x50px, PNG format)
- `tiktokLogo.png` - TikTok logo/icon (recommended: 50x50px, PNG format)
- `youtubeLogo.png` - YouTube logo/icon (recommended: 50x50px, PNG format)

## Notes
- All images should be optimized for web use
- PNG format is recommended for logos with transparency
- Consistent sizing will ensure proper display across devices
